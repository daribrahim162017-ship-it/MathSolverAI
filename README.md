# 🧮 MathSolverAI

### Your AI-Powered Mathematics Learning Assistant

**Understand the steps. Master the math. Build confidence.**

MathSolverAI is an educational AI project designed to help students solve mathematical problems, explore step-by-step explanations, and develop a deeper understanding of mathematics.

🔗 **GitHub Repository:** [MathSolverAI](https://github.com/daribrahim162017-ship-it/MathSolverAI)

## 🌟 What Is MathSolverAI?

MathSolverAI aims to make mathematics more accessible by combining a web-based interface, symbolic mathematics, and AI-assisted problem-solving.

Instead of focusing only on final answers, the project is designed around helping learners understand how mathematical problems can be solved.

Whether you're practising equations, exploring mathematical concepts, or building your problem-solving skills, MathSolverAI is an open-source project with room to grow.

## ✨ Features

* 🧠 **AI-Assisted Learning** — Support for exploring mathematical problems with AI.
* 🪜 **Step-by-Step Solutions** — Designed to help learners understand the reasoning behind answers.
* 📐 **Symbolic Mathematics** — Uses SymPy for supported mathematical operations.
* 💬 **Web-Based Interface** — Access the application through a browser when running locally.
* 🐍 **Python-Powered Backend** — Built using Python and Flask.
* 🏠 **Local AI Integration** — Supports an Ollama-based workflow where configured.
* 🚀 **Open for Contributions** — A project for developers interested in AI and education.

*Feature availability depends on the current implementation and configuration.*

## 🚀 Getting Started

Follow these steps to run MathSolverAI on your computer.

### Prerequisites

* Python 3
* Git
* A terminal or command prompt
* Ollama and the required model if you intend to use the local AI features

### 1. Clone the repository

```bash
git clone https://github.com/daribrahim162017-ship-it/MathSolverAI.git
cd MathSolverAI
```

### 2. Create a virtual environment

```bash
python3 -m venv venv
```

Activate it on macOS or Linux:

```bash
source venv/bin/activate
```

On Windows:

```bash
venv\Scripts\activate
```

### 3. Install the dependencies

```bash
pip install flask sympy pillow
```

If the project has a `requirements.txt` file, use it to install the project's complete dependency list:

```bash
pip install -r requirements.txt
```

### 4. Start the application

```bash
python app.py
```

### 5. Open MathSolverAI

Visit this address in your browser:

**http://127.0.0.1:5000**

The address works on the computer running the application. A public website requires separate deployment.
